## 1. ระบบนี้คืออะไร

แพลตฟอร์มสอบออนไลน์แบบ **MEQ (Modified Essay Question)**: การสอบแบบคุมเวลาและคุมสอบ

และหน้าจอภาษาไทยทั้งหมด

## 3. วิธีใช้งาน

**อาจารย์ (lecturer)**
1. **รายวิชาของฉัน** → สร้างรายวิชา
2. เปิดรายวิชา → **สมาชิก**: วางรายชื่ออีเมลนักศึกษา (วางได้หลายคนพร้อมกัน) แล้วเพิ่มเป็นนักศึกษา
   ใส่รหัสนักศึกษาต่อท้ายอีเมลในบรรทัดเดียวกันได้ เช่น `somchai_j@cmu.ac.th, 640610001`
   (นักศึกษาแต่ละคนต้องเคยล็อกอินเข้าระบบอย่างน้อยหนึ่งครั้งก่อน)
3. **การสอบ** → เพิ่มการสอบ → เปิดการสอบ
4. **1 · ตั้งค่า**: เขียนคำถาม แต่ละข้อมีโจทย์ ลิงก์รูป (มี preview) เฉลย เกณฑ์ให้คะแนน (rubric)
   คะแนนเต็ม และเวลาต่อข้อ มีแถบหมายเลขข้อให้กระโดดไปมา แก้แล้วบันทึกอัตโนมัติ
5. **2 · ดำเนินการสอบ**: กด **เริ่มสอบทันที** หรือ **ตั้งเวลาสอบ** ให้เริ่มเองตามเวลา
   มีนาฬิกานับถอยหลังตรงกับที่นักศึกษาเห็น และรายชื่อคุมสอบว่าใครเข้า/ส่ง/ออกจากหน้าจอสอบ (⚠)
6. **3 · ตรวจให้คะแนน**: ตรวจทีละคนหรือทีละข้อ พิมพ์คะแนนแล้ว **บันทึกอัตโนมัติ**
   จะเปิดตรวจล่วงหน้าด้วย AI ก็ได้ (ใช้ Anthropic API key ของอาจารย์เอง) หรือส่งออก CSV
   มีปุ่มส่งออกสองแบบ: **ส่งออกคะแนน CSV** และ **ส่งออกคำตอบทั้งหมด CSV** (เอาคำตอบไปตรวจนอกระบบได้)
7. กลับไปที่ **ดำเนินการสอบ** เมื่อปิดสอบแล้ว กด **ประกาศผลให้นักศึกษา**

**นักศึกษา (student)**
- **การสอบของฉัน**: การสอบที่กำลังจะมาถึง/กำลังสอบอยู่ด้านบน การสอบที่ผ่านมา (พร้อมคะแนน) ด้านล่าง
  หน้านี้แสดงรหัสนักศึกษาของตัวเองด้วย
- เข้าห้องรอสอบก่อนเวลาได้ มีนับถอยหลังและเริ่มเองอัตโนมัติ การสอบสดบังคับ **เต็มจอ (fullscreen)**
  ถ้าออกจากหน้าจอ/สลับแท็บจะถูกบันทึก
- หลังประกาศผล: **ดูผลสอบ** จะเห็นคะแนนและ feedback รายข้อ

**ผู้ดูแลระบบ (admin)** — กำหนดบทบาทผู้ใช้ และมีสิทธิ์ทุกอย่างของอาจารย์ด้วย

## 4. ฟีเจอร์หลัก

- หน้าจอ **ภาษาไทย** ทั้งหมด พร้อมตราคณะสัตวแพทยศาสตร์ CMU
- **เริ่มสอบอัตโนมัติตามเวลา** และ **ข้อสอบแบบ lockstep คุมเวลา** เลื่อนข้อทันที
- **ใช้ข้อสอบซ้ำได้**: คัดลอกข้อสอบไปใช้ปีถัดไปโดยไม่ต้องสร้างใหม่ ผลสอบเก่าเก็บแยกไว้
- **ล็อกหน้าจอระหว่างสอบ**: บังคับเต็มจอ ปิด copy/paste/คลิกขวา ตรวจจับการสลับแท็บและรายงานผู้คุมสอบ
- **เพิ่มนักศึกษาทีละหลายคน** ด้วยการวางอีเมล (ใส่รหัสนักศึกษาต่อท้ายได้)
- **ตรวจล่วงหน้าด้วย AI (Claude)** แบบ opt-in: อาจารย์ใส่ API key เอง ไม่เก็บคีย์ไว้ ค่าใช้จ่ายคิดกับคนที่กดตรวจ
  ค่าเริ่มต้นคือตรวจเองและฟรี
- **ตรวจให้คะแนนแบบบันทึกอัตโนมัติ** ไม่ต้องกดยืนยันทีละข้อ

## 5. ข้อมูลทางเทคนิค (สำหรับผู้ดูแลระบบ/ผู้พัฒนา)

- **Stack:** Next.js (App Router) + Supabase (Postgres, Auth, Realtime) + ปัจจุบันโฮสต์บน Vercel
- **โค้ด:** `Projects/2026/MEQ_Exam_System/meq-platform/`
- **Database migrations:** `meq-platform/supabase/migrations/0001…0017` (apply ครบแล้ว)
  ไฟล์รวม `supabase/ALL_MIGRATIONS.sql` ใช้สร้าง schema ใหม่บนโปรเจกต์เปล่าได้เกือบทั้งหมด
  หลังรันไฟล์รวมแล้วให้รัน migration ที่เลขสูงกว่าที่ไฟล์รวมมี (ล่าสุดคือ `0017_enrol_student_code.sql`) ต่อด้วย
- **Redeploy (บน Vercel เดิม):** ในโฟลเดอร์ `meq-platform/` รัน `npx vercel --prod`
  (อย่ารัน `next build` ขณะที่ `npm run dev` ทำงานอยู่ จะทำให้ dev build เสีย)
- **บัญชี:** ตอนนี้ Supabase project และ Vercel project อยู่ใต้บัญชีของ Aom
  หากส่งมอบให้คณะเต็มรูปแบบ คณะควรเป็นเจ้าของ (และเป็น data controller ตาม PDPA) ค่า env อยู่ใน Vercel project settings

## 6. ข้อจำกัดที่ทราบ / เรื่องที่ต้องตัดสินใจ

- **ยังไม่ได้ต่อ CMU SSO** ตอนนี้เปิดล็อกอินด้วยรหัสผ่านทดสอบไว้ เมื่อพร้อมให้ต่อ Microsoft Entra (ผ่าน CMU IT)
  แล้วตั้ง `NEXT_PUBLIC_ENABLE_PASSWORD_LOGIN` เป็น false และตั้ง Supabase Auth redirect URL เป็นโดเมนจริง
- **AI grading บนแพลนฟรี** จะแบ่งตรวจเป็นชุดเพื่อไม่ให้เกินลิมิต 60 วินาทีของ serverless
  ห้องเรียนใหญ่ยังตรวจได้ แต่ใช้หลายชุด
- **การล็อกเบราว์เซอร์มีข้อจำกัด** เต็มจอ + ตรวจจับคือระดับสูงสุดที่เบราว์เซอร์ปกติทำได้
  หากต้องคุมสอบเข้มระดับล็อกทั้งเครื่อง ใช้ **Safe Exam Browser (SEB)** หรืออุปกรณ์ kiosk ระบบรันใน SEB ได้เลย
- **เจ้าของระบบ/PDPA:** หากคณะจะใช้จริงเต็มรูปแบบ ควรย้ายบัญชี Supabase/Vercel และค่าใช้จ่ายไปเป็นของคณะ

## 8. คู่มือส่งต่อ Dev — นำระบบขึ้นเซิร์ฟเวอร์ Vet CMU (2026-08-04)

ระบบนี้เป็น **Next.js (App Router)** ต้องรันบนเซิร์ฟเวอร์ที่มี **Node.js 18 ขึ้นไป**
(ไม่ใช่ PHP/Apache แบบ static ล้วน) โดยทั่วไปรันด้วย `npm start` แล้ววาง nginx เป็น reverse proxy หน้าเว็บ
**หากเซิร์ฟเวอร์ Vet รองรับเฉพาะ PHP โปรดแจ้ง Aom ก่อน** เพราะต้องหา Node runtime หรือ container ให้ได้

**แนวทางที่แนะนำ (ง่ายและเสี่ยงน้อยที่สุด):** ใช้ **Supabase project เดิม** (`srekyxmcuhghyylzujqe`) ต่อไป
เพราะ Auth, ฐานข้อมูล, และ pg_cron (เริ่มสอบ/เลื่อนข้ออัตโนมัติ) ทำงานอยู่แล้ว
ย้ายเฉพาะส่วนหน้าเว็บ (Next.js) มาที่เซิร์ฟเวอร์ Vet เท่านั้น

### ขั้นตอนสำหรับ dev
1. **Node runtime:** ติดตั้ง Node.js 18+ แล้ว `npm ci` ในโฟลเดอร์ `meq-platform/`
2. **Environment variables** (ตั้งบนเซิร์ฟเวอร์ใหม่ ค่าจริงขอจาก Aom ห้าม commit ลง git):
   - `NEXT_PUBLIC_SUPABASE_URL=https://srekyxmcuhghyylzujqe.supabase.co`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY=` (ค่า public จาก Supabase)
   - `SUPABASE_SERVICE_ROLE_KEY=` (ค่า **ลับ** ใช้ฝั่งเซิร์ฟเวอร์เท่านั้น ห้ามหลุดไป client)
   - `NEXT_PUBLIC_ALLOWED_EMAIL_DOMAINS=cmu.ac.th`
   - `DEFAULT_NEW_USER_ROLE=student`
   - `NEXT_PUBLIC_ENABLE_PASSWORD_LOGIN=false`  ← **ต้องเป็น false บน production** ไม่ให้กล่องล็อกอินทดสอบโผล่ให้นักศึกษาเห็น
   - (ถ้าจะให้คณะออกค่า AI grading กลาง) `ANTHROPIC_API_KEY=`, `GRADING_MODEL=claude-opus-4-8`
3. **Build & run:** `npm run build` แล้ว `npm start` (หรือรันหลัง process manager เช่น pm2 / systemd)
4. **ฐานข้อมูล:** ถ้าใช้ Supabase project เดิม migration 0001–0017 apply ครบแล้ว ไม่ต้องทำอะไรเพิ่ม
   ถ้าตั้ง Supabase ใหม่ ให้รัน `supabase/ALL_MIGRATIONS.sql` แล้วตามด้วย migration ที่เลขสูงกว่า (ล่าสุด 0017)
5. **Supabase Auth เพิ่มโดเมนใหม่** (สำคัญ ไม่งั้นล็อกอินแล้วเด้งกลับ):
   Supabase Dashboard → Authentication → URL Configuration
   - ตั้ง **Site URL** เป็นโดเมนจริงของเซิร์ฟเวอร์ Vet (เช่น `https://exam.vet.cmu.ac.th`)
   - เพิ่มใน **Redirect URLs** ทั้ง `https://exam.vet.cmu.ac.th/**` และ `https://exam.vet.cmu.ac.th/auth/callback`

### เรื่อง CMU SSO (สำคัญมาก)
- **Redirect URI ที่ให้ CMU IT ไปลงทะเบียน Azure ไม่ต้องเปลี่ยน** แม้ย้ายเว็บมาเซิร์ฟเวอร์ Vet
  เพราะชี้ไปที่ Supabase: `https://srekyxmcuhghyylzujqe.supabase.co/auth/v1/callback` (ไม่ผูกกับโดเมนหน้าเว็บ)
- เมื่อ CMU IT ส่ง Client ID / Client secret / Tenant ID กลับมา ให้กรอกที่
  Supabase Dashboard → Authentication → Providers → **Azure** แล้ว Enable
  รายละเอียดคำขอ CMU IT อยู่ที่ `Notes/2026-08-04_CMU_IT_Azure_SSO_Request.md`

### สิ่งที่ dev ควรได้รับจาก Aom
โค้ดทั้งโฟลเดอร์ `meq-platform/`, ค่า env จริง (โดยเฉพาะ service role key), และสิทธิ์เข้าถึง Supabase project
หากคณะจะรับช่วงเป็นเจ้าของเต็มรูปแบบ ควรย้าย ownership ของ Supabase project ไปเป็นของคณะด้วย
(ประเด็น PDPA: คณะเป็น data controller)
